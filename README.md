# Rachad EL BARAKA - Portfolio BTS SIO SLAM

Portfolio professionnel moderne et interactif pour l'épreuve E5 "Support et mise à disposition de services informatiques".

## 🚀 Démarrage rapide

### Installation
```bash
npm install
```

### Développement
```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### Build pour production
```bash
npm run build
npm start
```

## 📁 Structure du projet

- `src/app/` - Pages Next.js avec App Router
- `src/components/` - Composants réutilisables
- `src/data/` - Données des projets (structure E5 complète)
- `public/` - Assets statiques

## 🎨 Technologies utilisées

- **Next.js 14** - Framework React avec App Router
- **TypeScript** - Typage statique
- **Tailwind CSS** - Framework CSS utilitaire
- **Architecture modulaire** - Composants réutilisables

## 📄 Pages

- **/** - Accueil avec présentation et stats clés
- **/projects** - Liste des projets avec filtres
- **/projects/[slug]** - Détails complets d'un projet (structure E5)
- **/skills** - Compétences techniques avec barres de progression
- **/experience** - Expériences professionnelles
- **/veille** - Veille technologique
- **/e5** - Page dédiée E5 avec tableau de synthèse
- **/contact** - Informations de contact

## 📊 Données projets

Les données des projets sont centralisées dans `src/data/projects.ts` avec la structure complète E5 :
- Contexte, objectifs, problématiques
- Démarche technique (architecture, stack, sécurité)
- Compétences BTS mobilisées
- Résultats, difficultés, améliorations
